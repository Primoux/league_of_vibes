# Archive — première phase (sept IA, une branche chacune)

Ces fichiers décrivent l'organisation **périmée** du projet : sept IA nommées, une branche longue par IA,
un `YOUR_PLAN.md` par branche. Ce modèle a été remplacé (voir `AGENTS.md`) quand le projet s'est ouvert à
plusieurs contributeurs apportant chacun leurs IA.

- `plans/` : la mission détaillée de chaque IA de la première phase. **Encore utile** comme mémoire du
  design par domaine (jalons, intentions, découpage technique), à ne pas lire comme une attribution de tâches.
- `progress/` : les journaux d'avancement de cette phase. L'avancement se suit désormais dans les issues.
